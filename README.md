# Rocket Mission Simulator 🚀

Rocket Mission Simulator is an interactive JavaFX application developed
for the TU/e 2IP90 Challenge-Based Learning project.

The user controls a rocket mission from launch to satellite deployment.
The simulator includes simplified rocket flight, live telemetry,
mission events, mission states, and mission success/failure conditions.
